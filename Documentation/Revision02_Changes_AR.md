# تحسينات النسخة الثانية بعد مراجعة الفيديو

تغيرت الشخصيات والحركة والخطوات والإضاءة والحوار داخل مشروع DesertShift نفسه. المهام الثلاث ما زالت تنتهي عند اتفاق الهروب مع مالك، كما طلبت.

| الجانب | التغيير الموجود في المشروع |
| --- | --- |
| الشخصية | موديلات موزونة جديدة، وجوه وشعر ولحى وملابس وتفاصيل يدين وأحذية؛ عشرة تصاميم تشمل الغليظ والنحيف والرياضي وألوان بشرة متنوعة. |
| المشي | سرعة وتسارع أهدأ، حركة للحوض والذراعين، ثني الركبتين وتثبيت القدم أثناء الخطوة، تنفّس وجلوس متدرج. |
| الخطوات | أربع نغمات للخرسانة وأربع للمعدن، مرتبطة بملامسة القدم بدل تشغيل صوت ثابت على توقيت منفصل. |
| الساحة | أربعة سجناء يتجولون وشرطي يدور في مسار، مجموعتان جالستان حول الطاولات، سجين يتمرّن، ومحادثات مسموعة عند الاقتراب. |
| طاولة البوكر | لعبة Five-card draw قابلة للعب، أوراق أصلية واضحة، اختيار KEEP، سحب مرة واحدة، كشف نتيجة اليد ومقارنة صحيحة للترتيب. |
| طاولة الحوار | جلوس ومحادثة اختيارية عن الناس وروتين الحراس، دون تجاوز مراحل القصة. |
| الإضاءة | نهار متأخر بدل العتمة الزرقاء في الفيديو، مصابيح داخلية دافئة، نوافذ مرتفعة، تقليل الوهج، وخامات خرسانة وقماش أدق. |
| الحوار والصوت | إعادة كتابة الحوار، 68 مقطعًا مولدًا بنموذج صوتي بخمس هويات صوتية، تحريك الفك والرأس واليدين أثناء الكلام، ترجمة أكبر وإمكانية تقديم الجملة. |
| تفاصيل المكان | أوراق ورقائق بوكر وكراسي وأكواب وصحف، أدوات تمرين، سلة كرة، وتفاصيل السور والإنارة. |
| الحفظ والوقف | الحفاظ على مراحل المهمة؛ إغلاق البوكر عند بدء مشهد القصة، الحفظ خارج مقعد الطاولة، وإيقاف المؤقتات والأصوات عند Pause. |

## ما بقي من طلبك الأول

- حادث السكين بعد روتين الساحة، وإخفاؤه في الوقت المحدد: **Mission completed** بالأخضر وصوت نجاح، أو **Missed** بالأحمر وصوت فشل وإعادة المحاولة.
- احترام العصابة، الانضمام والوشم، ثم إخفاء السكين في B-04 قبل الحصول على الهاتف.
- الهاتف والمكالمة، الشجار مع العصابة المنافسة، وزنازين انفرادية منفصلة. تمر 24 ساعة خلال 60 ثانية لعب أثناء النوم.
- طرق الشرطي، زيارة الأخ الباكي، خبر اختطاف الأب، العودة والتفكير، ثم اتفاق الهروب المشترك قبل الأسبوع القادم.

## نتيجة التحقق

نجحت **84** حالة تحقق لمنطق القصة الفعلي و**1,171** حالة لقواعد البوكر الفعلية. نجحت مراجعة مراجع الأصول وملفات الحوار والصور والصوت، واختبار نوعي للصيغ البرمجية باستعمال واجهات Unity مؤقتة.

محرر Unity غير متوفر هنا، لذلك لم يتم تشغيل Play Mode أو بناء ملف Windows تنفيذي أو قياس الأداء. صور `BlackstonePreviews` معاينات هندسية خارج Unity، وموسومة بذلك؛ لا تمثل التصيير النهائي أو الحركة داخل اللعبة. المشروع يحتوي على المصدر والأصول الجاهزة للاستيراد، مع قائمة اختبار تشغيل واضحة.
