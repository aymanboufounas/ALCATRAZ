# Revision 05 asset credits

## Microsoft Rocketbox — MIT

Five complete facial models, source textures and 12 animation FBXs are from [Microsoft-Rocketbox](https://github.com/microsoft/Microsoft-Rocketbox), snapshot `0943055db6ec570bcef9f2c8b41c9e5467c808f9`.

- Profiles: `Male_Adult_07`, `Male_Adult_12`, `Male_Adult_16`, `Male_Adult_17`, `Male_Adult_20`.
- Clips: neutral idle, slow/normal/fast walks, normal/fast runs, start/stop, left/right turns, crouch idle and seated idle.
- Original copyright/MIT notice: [Microsoft_Rocketbox_MIT.md](Licenses/Microsoft_Rocketbox_MIT.md).
- Source URLs, Git blob SHA-1 and packaged SHA-256: `Revision05_RocketboxProvenance.json`.
- Adaptations: PNG conversion, URP materials, clothing colors, height normalization, size variants, root anchoring and pose overlays.

Model/clip FBX bytes remain unchanged. Converted PNGs/portraits are listed in provenance. Adapted clothing PNGs are additional files; originals remain included. Previews use actual source meshes/textures.
