# Open Alcatraz Escape

1. Download this repository ZIP and extract it, or clone the repository.
2. In Unity Hub, add the folder containing Assets, Packages and ProjectSettings.
3. Use Unity 6000.0.62f1 and wait for import to finish.
4. Choose Alcatraz > Open Island, then Play.
5. Choose Play Chapter 01 on the game's menu for the story.

WASD moves, mouse looks, Shift runs, E interacts, hold M opens the island map, Esc pauses.

If characters have not prepared automatically, choose Alcatraz > Prepare Characters and inspect the Console. Build through Alcatraz > Build Windows x64 after installing Windows Build Support.

This is a Unity source project, not an included Windows executable. Revision 08 follows the approved concept using existing rigs and original geometry. Import and Play Mode still need verification in Unity.
